Esercizio


Studiare il segno del polinomio \[ 8x^2 + x + 1 \] al variare del valore della \(x\).

Soluzione
Si ha \(8x^2 + x + 1 \gt 0\) per ogni valore \(x \in \mathbb{R}\).

Svolgimento




Esercizio


Studiare il segno del polinomio \[ -7x^2 + 4x \] al variare del valore della \(x\).

Soluzione

  • \(-7x^2 + 4x \gt 0\)

    se \(\quad 0 \lt x \lt \dfrac{4}{7} \quad\)

  • \(-7x^2 + 4x \lt 0\)

    se \(\quad x \lt 0 \quad\) oppure \(x \gt \dfrac{4}{7}\)

  • \(-7x^2 + 4x = 0\)

    se \(\quad x = 0 \quad\) oppure \(x = \dfrac{4}{7}\)
