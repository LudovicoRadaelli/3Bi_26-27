Equazioni di secondo grado: ormula risolutiva



Data l'equazione \[ \color{red}{a}\,\color{black}{x^2}\, + \color{blue}{b}\,\color{black}{x}\, + \color{darkorange}{c}\,\, \color{black}{}= 0 \] la forumula risolutiva è \[ x = \dfrac{-\color{blue}{b}\color{black}{} \pm \sqrt{\color{blue}{b}\color{black}{}^2 - 4 \cdot \color{red}{a}\color{black} \cdot \color{darkorange}{c}\color{black}}}{2\color{red}{a}} \]




Esercizio


Risolvere l'equazione \[ 5x^2 -7x + 2 = 0 \]
Soluzione
L'equazione è risolta per \(x = \dfrac{2}{5}\) oppure \(x = 1\)

Esercizio


Risolvere l'equazione \[ 8x^2 +10x -3 = 0 \]
Soluzione
L'equazione è risolta per \(x = -\dfrac{3}{2}\) oppure \(x = \dfrac{1}{4}\)

Soluzione
L'equazione è risolta per \(x = -1\) oppure \(x = \dfrac{3}{41}\).
