Esercizio


Studiare il segno del polinomio \[ -x^2 -10x -21 \] al variare del valore della \(x\).

Soluzione

\(-x^2 -10x -21 \gt 0\,\,\) se \(\,\, -7 \lt x \lt -3\)

\(-x^2 -10x -21 \lt 0\,\,\) se \(\,\,x \lt -7\,\,\) oppure \(\,\,x \gt -3\)

\(-x^2 -10x -21 = 0\,\,\) se \(\,\,x = -7\,\,\) oppure \(\,\,x = -3\)

Risolvere la seguente disequazione di secondo grado usando il metodo della parabola. \[ (8x + 3)(1 - 4x) - 20x^2 \leq 5x -(11 + 7x) \]
Soluzione
La disequazione è risolta per \(\,\,\, x \leq -\dfrac{7}{13}\,\,\) oppure \(\,\,\, x \geq \dfrac{1}{2}\)
